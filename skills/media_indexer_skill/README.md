# media_indexer_skill

AdaOS-скилл для семантической индексации локальных медиафайлов.
Поддерживает будущую обработку видео, аудио и изображений.
Скилл сканирует директории и строит поисковый индекс.
Поиск выполняется по естественно-языковым запросам.
В основе используются NER, FAISS, CLIP и внешнее обогащение метаданных.
